macOS Developer Cleanup

mac-dev-cleanup

扫描、分析并安全清理 macOS 开发者缓存、依赖与构建产物——带本地 Web 控制台、JSON 策略，以及可一键恢复的「先进废纸篓」清理。

特性

一个脚本搞定从「发现占用」到「安全回收」的完整闭环。

广覆盖识别

识别 13 类目标：全局缓存、应用缓存/日志、项目生成物、测试产物、截图、大目录/大文件、stale 依赖与模型等。

三级风险模型

safe / aggressive / manual。manual 项（截图、大文件、模型等）永不自动删除，仅报告待人工确认。

Stale 项目识别

以「源码 mtime + 最后 git commit」判定项目闲置（默认 90 天），自动把闲置项目的依赖标为 stale-deps、模型标为 stale-model。

先进入废纸篓

真实清理把候选移入 ~/.Trash/mac-dev-cleanup/<op-id>/，写入操作清单，可一键还原。绝不使用裸 rm。

配置化

单一 config.json 管理阈值、扫描根、排除项；Web 设置面板可视化编辑并原子写入，未知键会被拒绝。

本地 Web 控制台

自包含零依赖仪表盘：查看状态、改配置、触发只读扫描。小屏自动切换卡片视图，无横向滚动。

APFS 感知

清理后空间未必立即释放——APFS 快照会占位。文档说明重启释放机制与正确验证姿势（df -h ~）。

安全边界硬编码

个人媒体/文档/源代码/.git/lockfile 受保护；配置只能「加保护」，无法削弱系统级安全边界。

风险级别

清理前务必先扫描；不同模式对各级别的处理不同。

级别行为典型示例
safeclean-safe 与 clean-aggressive（加 --apply）均删除__pycache__、pip/npm/uv 缓存、playwright 临时文件、项目日志、覆盖率
aggressive仅 clean-aggressive（加 --apply）删除node_modules、.venv、build、dist、Codex/Trae 缓存、大应用缓存/日志、stale-deps
manual任何模式都不自动删除，报告中标为「待确认」截图、大目录、归档、dump、个人大文件、stale-model

安装与使用

纯 Python 标准库，无需 pip 安装第三方包。

1 · 获取

# 克隆仓库（或把技能目录拷到本地） git clone https://github.com/yancongya/mac-dev-cleanup.git # 技能默认位于： # ~/.codex/skills/mac-dev-cleanup/

2 · 扫描（只读，不清理）

python3 ~/.codex/skills/mac-dev-cleanup/scripts/mac_dev_cleanup.py scan

3 · 安全清理（先试跑，再真正执行）

# 干跑：只报告会删什么 python3 ~/.codex/skills/mac-dev-cleanup/scripts/mac_dev_cleanup.py clean-safe # 真正清理：移入废纸篓（可恢复） python3 ~/.codex/skills/mac-dev-cleanup/scripts/mac_dev_cleanup.py clean-safe --apply

4 · 还原 / 激进清理

# 列出 / 还原操作 python3 ~/.codex/skills/mac-dev-cleanup/scripts/mac_dev_cleanup.py --list-operations python3 ~/.codex/skills/mac-dev-cleanup/scripts/mac_dev_cleanup.py --restore <operation-id> # 激进模式（含项目依赖/构建目录） python3 ~/.codex/skills/mac-dev-cleanup/scripts/mac_dev_cleanup.py clean-aggressive --apply

5 · 本地 Web 控制台

python3 ~/.codex/skills/mac-dev-cleanup/scripts/web_server.py # 浏览器打开： # http://127.0.0.1:8765/dashboard.html

配置（config.json）

用户可调项集中在 config.json；脚本每次运行读取，缺失则写入默认值。

{ "stale_days": 90, "thresholds": { "app_cache_min_mb": 50, "app_log_min_mb": 10, "large_dir_mb": 100, "large_file_mb": 50 }, "scan_roots": ["~/工作/开发", "~/Desktop/OH-WorkSpace", "~/Documents", "~/Developer", "~/dev", "~/workspace"], "personal_roots": ["~/Desktop", "~/Pictures", "~/Downloads"], "exclude_paths": [], "exclude_globs": [], "protected_projects": [], "protected_categories": [], "trash_retention_days": 30 }
# 查看当前配置 python3 ~/.codex/skills/mac-dev-cleanup/scripts/mac_dev_cleanup.py --show-config # 写入配置（校验后原子替换） echo '{"stale_days":30}' | python3 ~/.codex/skills/mac-dev-cleanup/scripts/mac_dev_cleanup.py --set-config

安全须知

清理有风险，请先在废纸篓里留存一段时间再清空。

APFS 快照占位：macOS 删除大文件后 df 可能不变——系统更新快照 com.apple.os.update-* 与 Time Machine 本地快照会占用容器空间。重启是最可靠的释放方式，不要因为 df 没变就以为清理失败。验证请用 df -h ~（而非 df /，后者在 modern macOS 上是只读系统卷）。

受保护、永不被扫描/删除的范围：个人媒体与文档、应用支持数据、源代码、.git、包 lockfile、用户自建资源；项目遍历时跳过 .git/.svn/.hg；系统目录（Application Support、Containers、Mobile Documents、Music、Movies、Trash 等）不进入。

扫描根：项目目录递归 个人根：仅顶层（截图/大文件） 应用根：仅 ≥50M 缓存 / ≥10M 日志 临时根：/tmp、/var/folders
